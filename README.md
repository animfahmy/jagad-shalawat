# Jagad Shalawat Landing Page

Repositori ini berisi *source code* untuk halaman utama (landing page) website Majelis Ta'lim dan Dzikir Jagad Shalawat, Malang. 

Halaman ini dibangun dengan niat sederhana: menyediakan informasi kegiatan rutin dan agenda majelis secara jelas, agar mudah diakses oleh jamaah.

## Teknologi
*   HTML5 & CSS3
*   Tailwind CSS (dimuat secara lokal)
*   Vanilla JavaScript (untuk *countdown* dinamis)
*   Lucide Icons & Flag Icons

Untuk menjaga keamanan dan kemandirian website, seluruh aset *library* pihak ketiga telah diunduh dan disimpan secara lokal di dalam direktori `assets/`. Hal ini bertujuan untuk meminimalisasi risiko ketergantungan pada CDN luar (*supply chain attacks*).

## Cara Penggunaan
Cukup buka file `index.html` menggunakan web browser apa pun. Kode ini sepenuhnya statis, sehingga tidak memerlukan proses _build_ atau instalasi server khusus.
